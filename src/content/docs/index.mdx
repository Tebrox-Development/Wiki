## Documentation policy

The wiki documents the **current stable version** of each plugin.

When a plugin has a public beta or preview that differs meaningfully from stable, its beta documentation is kept in a clearly separated beta section. Once that version becomes stable, the beta documentation replaces the previous stable documentation.

Breaking upgrades can keep a dedicated migration guide where needed.
