# EggEmAll Reloaded

EggEmAll Reloaded lets server owners catch supported mobs with eggs, preserve supported entity data, and spawn them again later.

This section will collect installation, configuration, commands and permissions, integrations, migration notes, and troubleshooting in the same structure as the other plugins.
